TV + CARD ANIMADOS — @bomfixm

1. Extraia este pacote.
2. No GitHub, crie (ou abra) o repositório público chamado bomfixm.
   Ele precisa pertencer à conta bomfixm para aparecer no perfil.
3. Envie o README.md e a pasta assets para a raiz desse repositório.
   Se já usa a versão anterior, atualize o README e envie os novos arquivos do card.
4. Confirme o envio com Commit changes.

O README já exibe o card abaixo da TV. Ambos são GIFs em loop.
Não há link para o portfólio e não é preciso adicionar outras seções.
Os PNGs em assets são alternativas estáticas. O README usa os GIFs.
A pasta source contém o desenho editável e a foto original do passe.
Não precisa enviá-la para o GitHub.

Para regenerar: Python 3, Pillow e NumPy.
Execute source/generate_card.py para a TV e source/generate_pass.py para o card.
